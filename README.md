# 數獨 Sudoku

9×9 數獨遊戲，單一 HTML 檔，手機與電腦皆可玩。直接用瀏覽器開啟 `index.html` 即可。

- 下方數字鍵盤點選填入，不需打字
- 五種難度（入門適合小學生）、筆記模式、復原、擦除、提示、錯誤標示、計時
- 進度自動儲存在瀏覽器

# 國字釣魚（hanzi-tracing）

給小一孩子練習國字的釣魚遊戲，手機、平板用手指操作。用瀏覽器開啟 `hanzi-tracing/index.html` 開始。

- `index.html`：釣魚（入口）。魚的大小代表這個字學到哪裡，釣到後進入對應關卡
- `level1.html`：第一關，看圖選字（小魚）
- `level2.html`：第二關，描紅（中魚，需要網路）
- `level3.html`：第三關，默寫（大魚、金色的魚，需要網路）
- `game-data.js`：共用的字表和進度紀錄。新增練習的字請改這裡
