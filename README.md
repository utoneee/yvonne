# 小遊戲樂園

用瀏覽器打開 `index.html` 會看到遊戲選單，可以選要玩哪個遊戲。

## 數獨 Sudoku

9×9 數獨遊戲，單一 HTML 檔，手機與電腦皆可玩。直接用瀏覽器開啟 `sudoku.html` 即可。

- 下方數字鍵盤點選填入，不需打字
- 五種難度（入門適合小學生）、筆記模式、復原、擦除、提示、錯誤標示、計時
- 進度自動儲存在瀏覽器

## 終極密碼

猜數字遊戲（單人版）：五種難度、內建數字鍵盤（橫螢幕自動左右排）、鎂棒打火石生火動畫、音效、猜測次數、按住「偷看一下」看範圍，森林營火露營風。直接用瀏覽器開啟 `guess-number.html` 即可。
