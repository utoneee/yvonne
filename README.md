# 小遊戲樂園

用瀏覽器打開 `index.html` 會看到遊戲選單，可以選要玩哪個遊戲。

## 數獨 Sudoku

9×9 數獨遊戲，單一 HTML 檔，手機與電腦皆可玩。直接用瀏覽器開啟 `sudoku.html` 即可。

- 下方數字鍵盤點選填入，不需打字
- 五種難度（入門適合小學生）、筆記模式、復原、擦除、提示、錯誤標示、計時
- 進度自動儲存在瀏覽器

## 終極密碼

猜數字遊戲（單人／雙人）：雙人可選四種小動物、抽籤決定誰先猜；五種難度、內建數字鍵盤（橫螢幕自動左右排）、扁平插畫風森林帳篷場景、鎂棒打火石生火動畫（猜錯冒煙、猜對升起營火）、音效、猜測次數、按住「偷看一下」看範圍。直接用瀏覽器開啟 `guess-number.html` 即可。

## 鼴鼠大胃王 Mole Muncher

開啟 `mole.html` 即可遊玩。控制星鼻鼴在地底隧道裡追著蟲跑，60 秒內把蟲全部吃光。

- 移動像經典迷宮遊戲：鼴鼠會一直往前跑，到路口才轉彎，可以先按好下一個方向（方向鍵／WASD／手機滑動或方向鍵）
- 撞到土牆後繼續按住同方向可以挖出新隧道，石頭挖不動
- 蚯蚓等簡單的蟲會加時間；甲蟲、蟋蟀、蜈蚣等抓到後要「連打」扭打
- 第 7 關起地底變暗，用空白鍵／「嗅」偵測蟲的位置
- 10 種昆蟲、12 個設計關卡，之後是無限挑戰
- 星星：吃光時剩超過 20 秒 ★★★、10–20 秒 ★★、10 秒內 ★

## 設計稿

`designs/campfire-design.html`：營火設計稿（三種扁平插畫風背景：A 森林帳篷、B 湖邊營地、C 山頂大岩石，加上生火動畫試玩）。B、C 之後會當成可以解鎖的背景。
