# 數獨 Sudoku

9×9 數獨遊戲，單一 HTML 檔，手機與電腦皆可玩。直接用瀏覽器開啟 `index.html` 即可。

- 下方數字鍵盤點選填入，不需打字
- 五種難度（入門適合小學生）、筆記模式、復原、擦除、提示、錯誤標示、計時
- 進度自動儲存在瀏覽器

# 鼴鼠大胃王 Mole Muncher

開啟 `mole.html` 即可遊玩。控制星鼻鼴在地底隧道裡追著蟲跑，60 秒內把蟲全部吃光。

- 移動像經典迷宮遊戲：鼴鼠會一直往前跑，到路口才轉彎，可以先按好下一個方向（方向鍵／WASD／手機滑動或方向鍵）
- 撞到土牆後繼續按住同方向可以挖出新隧道，石頭挖不動
- 蚯蚓等簡單的蟲會加時間；甲蟲、蟋蟀、蜈蚣等抓到後要「連打」扭打
- 第 7 關起地底變暗，用空白鍵／「嗅」偵測蟲的位置
- 10 種昆蟲、12 個設計關卡，之後是無限挑戰
- 星星：吃光時剩超過 20 秒 ★★★、10–20 秒 ★★、10 秒內 ★
